# Automação — 0.2

Já existem sessões assistidas, leitura limitada e controle amplo supervisionado do perfil pessoal, com escopo, prazo, STOP/revogação e auditoria. O chat Qwen usa propostas estruturadas; ações externas e gravações pedem confirmação.

Ainda não existe planejador autônomo de múltiplas tarefas, automação GUI genérica ou execução arbitrária de scripts. Antes de ampliar: estado de tarefas, idempotência/recuperação, aprovações críticas, isolamento por app e testes adversariais. Não confundir autorização ampla do perfil com controle irrestrito do Windows.
